# VEYRA Kinetix V-01

Static product concept site, ready for GitHub Pages. The page and its image are in the repository root, so no build step is needed.

## Publish

1. Put the contents of this folder in the root of a GitHub repository.
2. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
3. Push to the `main` branch, or run the **Deploy VEYRA site to GitHub Pages** workflow from the Actions tab.

The workflow publishes `index.html` and `veyra-kinetix-v01.png`. All proposed hardware figures on the page are clearly identified as concept targets.
